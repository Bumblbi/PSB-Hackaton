# Рабочее место юриста

React + TypeScript + Vite. Интерфейс работает с FastAPI и сохраняет историю
на сервере. Юридические ответы не имитируются на клиенте. Шрифты и иконки
поставляются локально, без запросов к CDN.

## Разработка

Сначала запустите бэкенд из `backend/` по корневому README. Затем:

```powershell
cd frontend
npm.cmd ci
npm.cmd run dev
```

Откройте http://127.0.0.1:5173. Vite проксирует `/api` и `/health` на порт 8000.
Первый вход выполняется через регистрацию. Диалоги привязаны к пользователю.
Cookie сессии имеет HttpOnly, CSRF-токен хранится в памяти приложения.
Смена пароля завершает все сеансы учётной записи.
На Linux/macOS используйте `npm` вместо `npm.cmd`.
Для другого адреса API задайте `API_PROXY_TARGET` в окружении при запуске Vite.
Ключи LLM должны оставаться в `backend/.env`.

## Проверки

```powershell
npm.cmd run test
npm.cmd run build
npx.cmd playwright install chromium
npm.cmd run test:e2e
```

E2E требует установленных Python-зависимостей бэкенда. По умолчанию используется
`python`; если зависимости в venv, задайте `E2E_PYTHON` с путём к Python из venv
(путь с пробелами оберните в кавычки внутри значения). Тесты запускают собственные
серверы на 8001 и 5174, временную SQLite и gateway из `backend/tests/conftest.py`.
Рабочая БД и ключи провайдеров в E2E не используются. Этот gateway не выбирается
через production-настройки. Порты тестов должны быть свободны.

Проверяются вопрос → API → сохранение в SQLite → ответ → ссылка → точная редакция
и подсветка → восстановление истории. Отдельно проверяются фильтры, недоступность
провайдера, защита от повторной отправки, мобильная навигация и WCAG через axe.
Снимки для визуальной проверки лежат в игнорируемом `test-results/`.

## Сценарии интерфейса

- Новый диалог создаётся при первой отправке, без пустых чатов от каждого клика
- Регистрация, вход, выход и смена пароля доступны в интерфейсе
- Дата и тип документа доступны в «Уточнить контекст»
- В библиотеке можно найти документ, прочитать редакцию и задать вопрос по нему
- Номер ссылки открывает ровно ту редакцию и фрагмент, которые вернул сервер
- Недостаток оснований, отсутствие исторической редакции и уточнение не скрываются
- При сбое вопрос остаётся в поле ввода; автоматическая повторная отправка отсутствует
- Enter отправляет вопрос, Shift + Enter добавляет строку; на сенсорном устройстве
  Enter добавляет строку, отправка выполняется кнопкой
- Диалоги доступны по ссылке `/#/chat/{id}`; библиотека — `/#/documents`

Дизайн следует направлению «юридическое дело»: спокойная светлая рабочая область,
тёмная навигация, нумерация оснований и выделение цитаты. Сетка 4 px, локальный
IBM Plex Sans, Lucide, видимый фокус и поддержка reduced motion.
Атрибуция методики unslop — в `THIRD_PARTY_NOTICES.md`.
